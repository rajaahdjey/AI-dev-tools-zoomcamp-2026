
# Project Instructions

## Backend dependency management

- Use `uv` for Python dependency management.
- Do not use pip directly to install or manage project dependencies.

Useful commands:

```bash
uv sync
uv add <PACKAGE-NAME>
uv run python <PYTHON-FILE>
```

## Git workflow

- Commit code regularly as you complete meaningful changes.
- Write clear, descriptive commit messages.
- Before committing, review the changes and ensure the code is in a working state.
